# 学习通适配笔记

从 ocsjs（MIT）逆向得到、并在本项目实测有效的页面契约。改选择器前先读这里。

## 页面形态

| URL 特征 | 形态 | 根选择器 | 翻页 |
|---|---|---|---|
| `/mooc2/exam/preview` | 整卷预览 | `.questionLi` | 无需 |
| `/mooc2/work/dowork` | 作业 | `.questionLi` | 无需 |

## 元素

```
题目容器   .questionLi
题干       .mark_name / :scope > h3 / .splitS-left .mark_name
选项       .answerBg .answer_p, .textDIV, .eidtDiv      ← 有嵌套，必须去重
题型       input[name^="type"]（名形如 type0/type1…）
作业题型   input[id^="answertype"]
已选标记   [class*="check_answer"]（落在 .answer_p 或 a.answerBg 或 li 上，位置会漂）
填空       textarea / input[type=text] / iframe(富文本)
保存       [onclick*="saveQuestion"]
解析区     .mark_answer（解析正文，必须排除，否则会被当成选项）
```

## 题型码（`input[name^=type].value`）

| 值 | 题型 | 本项目映射 |
|---|---|---|
| 0 | 单选 | `single` |
| 1 | 多选 | `multiple` |
| 3 | 判断 | `judgement` |
| 2,4,5,6,7,8,9,10 | 填空/简答/论述等 | `completion` |
| 11 | 连线 | `line` |
| 14 | 完形填空 | `fill` |
| 15 | 阅读理解 | `reader` |

`line` / `reader` 按选择题路径处理（有选项就点，无选项写文本）。

## 字形加密

- 加密元素带 class `font-cxsecret`，字体以 base64 data URI 内联在 `<head><style>`：
  `url(data:font/...(;base64,([\w\W]+?)['")])`
- 特征表格式 `FRB2`：`magic(4B) + count(u32LE) + threshold(u32) + gc(u32) + gf(u32) + cps[count](u32) + coarse位图 + fine位图`，位按 MSB 优先打包。
- 渲染参数必须与生成端一致：`RENDER=360`、`SQ=480`、`BASELINE=384`、`SHORTLIST=40`、`INK_THRESHOLD=40`。
- 距离用汉明距离；`margin = 1 - best/second`，margin < 0.3 说明形近字有歧义，应把该题置信度压低。
- 判断某元素是否被加密字体覆盖：同文本分别用衬线体与无衬线体渲染，像素差 < 1000 判为覆盖。

## 已知坑

1. **选项重复**：`.answerBg .answer_p` 内部的 `.textDIV` 也会命中，不去重 4 选项会变 8 个，答案字母全错位。
2. **勾的位置漂移**：不同版本把 `check_answer` 打在 `.answer_p`、`a.answerBg` 或 `li` 上，检测要查三层。
3. **点击不生效**：只调 `el.click()` 在部分版本无效，必须补 `pointerdown/mousedown/mouseup` 序列；仍不行就点父级 `li`。
4. **题型 input 是干扰项**：非预览页有多个 `input[name^=type]`，只认名字匹配 `/^type\d+$/` 的那个。
5. **切屏检测**：`visibilitychange` + `blur` + `document.hidden` 三处都会上报，需同时处理。
6. **交卷按钮文案**：`交卷` / `提交试卷` / `提交答案` / `提交`，自动确认弹窗时务必排除这些词。
