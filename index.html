🧠 CX 考试 AI 大脑 · 学习通考试自动答题

不用题库。每道题现场交给多个大模型独立作答，再交叉复核、分歧仲裁，最后拟人化地点到页面上。

一键安装

CLOUDFLARE Cloudflare 安装 国内高速 CDN，推荐国内用户使用 → 点此安装（本站） GITHUB GitHub 安装 国际同步，随时取最新源码与提交记录 → raw 直链 GREASY FORK Greasy Fork 安装 全球最大油猴脚本库，支持自动更新 → 装一次，之后自动更新
前置：浏览器已装 Tampermonkey； 并在 chrome://extensions/ 打开右上角「开发者模式」，进 Tampermonkey 详情页开启「允许运行用户脚本」。

它解决的四件事

抓题不准
按考试页真实 DOM 层级解析，兼容整卷 .questionLi 与章节 .TiMu 两套结构，嵌套元素去重。
字形加密
识别 font-cxsecret 内联 base64 字体 → 360px 渲染 → 积分图降采样 → FRB2 汉明距离匹配还原。
答案不准
多模型议会：独立作答 → 交叉复核 → 仲裁，加权一致率达标才采纳，低置信度标黄留给人工。
被判定非人类
完整指针事件序列 + 随机落点 + 随机间隔 + 概率长停顿，点完必复核选中态。

独立设置中心

不用进考试页也能配模型。打开设置中心，左侧分类里改模型 / 判题 / 读图 / 运行参数，改完即时保存， 回到考试页直接生效（油猴存储在同一脚本内跨域名共享）。前提：脚本版本 ≥ 1.8.0。

SETTINGS 打开设置中心 → 模型与 Key、判定强度、读图策略、作答节奏、配置备份、诊断 → 由脚本渲染的真实设置页

三步用起来

  1. 装好脚本后打开考试页，右下角出现 CX 悬浮球，Ctrl+Shift+X 呼出面板。
  2. 点 ⚙ 配置模型：至少一个判题模型（DeepSeek / 自定义 / magpie 本地网关），题目带图再加一个读图模型。
  3. 点「测试连接」看到 连通 (xxx ms)，回到面板点「开始」。

交卷永不自动点，除非显式勾选「自动交卷」（勾了也会先停 10 秒等你反悔）；含「交卷/提交试卷」的按钮脚本一律不碰。
